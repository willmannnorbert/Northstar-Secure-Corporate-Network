3. FW-NORTHSTAR – IOS ZONE-BASED FIREWALL + PAT
======================================================================

hostname FW-NORTHSTAR
enable secret password123
service password-encryption
username admin privilege 15 secret password123
ip domain-name northstar.local
crypto key generate rsa
ip ssh version 2

banner motd #WARNING: Authorized Northstar personnel only. Unauthorized access is prohibited.#

interface FastEthernet0/0
 description INSIDE_TO_R-HQ
 ip address 10.10.200.2 255.255.255.252
 zone-member security INSIDE
 ip nat inside
 no shutdown

interface FastEthernet0/1
 description OUTSIDE_TO_R-ISP
 ip address 203.0.113.2 255.255.255.252
 zone-member security OUTSIDE
 ip nat outside
 no shutdown

ip route 0.0.0.0 0.0.0.0 203.0.113.1
ip route 10.10.0.0 255.255.0.0 10.10.200.1

ip access-list standard NAT_ELIGIBLE
 permit 10.10.10.0 0.0.0.63
 permit 10.10.20.0 0.0.0.127
 permit 10.10.30.0 0.0.0.31
 permit 10.10.50.0 0.0.0.31
 permit 10.10.60.0 0.0.0.31

ip nat inside source list NAT_ELIGIBLE interface FastEthernet0/1 overload

zone security INSIDE
zone security OUTSIDE

class-map type inspect match-any ALLOWED_TRAFFIC
 match protocol http
 match protocol https

policy-map type inspect WEB_POLICY
 class type inspect ALLOWED_TRAFFIC
  inspect

zone-pair security INSIDE_TO_OUTSIDE source INSIDE destination OUTSIDE
 service-policy type inspect WEB_POLICY

ip access-list standard MGMT-SSH
 permit 10.10.10.0 0.0.0.63
 deny any

line vty 0 4
 access-class MGMT-SSH in
 exec-timeout 5 0
 login local
 transport input ssh

NOTE: VLAN40 Servers and VLAN70 CCTV are intentionally excluded from
NAT_ELIGIBLE. ZBF inspects HTTP/HTTPS; ICMP is not part of the policy.

12. EXPECTED SECURITY BEHAVIOR
======================================================================

- Eligible user VLANs reach the public HTTP server through PAT + ZBF.
- Investigations can use authorized server services while protected VLAN access
  is restricted.
- Guest clients receive centralized DHCP but cannot directly access corporate
  VLANs.
- Branch clients receive DHCP across the routed/OSPF connection.
- Management and IT can access the simulated NVR.
- CCTV cannot initiate arbitrary routed connections.
- VLAN40 Servers and VLAN70 CCTV do not receive general Internet PAT.
- Firewall SSH is allowed from VLAN10 and denied from unauthorized networks.
- External hosts cannot initiate arbitrary connections into internal networks.

======================================================================
13. LAB DESIGN NOTES
======================================================================

The final perimeter uses an IOS Zone-Based Firewall instead of the original
Packet Tracer ASA 5506-X attempt. During the ASA experiment, inside HTTP reached
the public server and return traffic was reverse-translated, but the tested
Packet Tracer behavior did not provide a satisfactory scalable return-flow
implementation for this topology. The working design was therefore rebuilt
using IOS ZBF.

The lab demonstrates defense in depth using VLAN segmentation, ACLs, OSPF,
PAT, ZBF and restricted SSH management.

NAT eligibility is not treated as a substitute for access-control policy.

203.0.113.0/24 and 198.51.100.0/24 are documentation/test address ranges used
for the simulated external network.
